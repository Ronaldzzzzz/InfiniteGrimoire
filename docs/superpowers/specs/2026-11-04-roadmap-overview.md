## 10. 新的實作順序與切割（2026-11-06，使用者核准）

依據：`2026-11-04-item-catalyst-discussion.md` 第 1～13 節的框架討論。**本節取代第 8 節的順序。** 每一列是一個獨立專案：各自走「規格 → 計畫 → 實作 → 驗收」，計畫等真正要開始時才寫。

### 10.1 依賴關係
- 物品圖鑑（P1）是幾乎所有新系統的地基：催化劑、異變、採集、主城、煉金、委託商、抽獎、排行都要它。
- 一般異變由物品特性觸發 → 熟練度與異變（P3）在物品之後。
- 光暗元素靠異變解鎖 → 光暗（P6）在異變之後。
- 採集區與主城都是地圖上的圓點 → 地圖改版（P7）在它們之前。
- 煉金、委託商、抽獎、倉庫只能在主城用 → 主城骨架（P9）在它們之前。
- 煉金配方沿用靈光機制 → 書與靈光（P4）在煉金之前。
- 雙重詠唱與元素反應不依賴物品，可以提早或與其他專案交錯；光暗湮滅反應等光暗（P6）。

### 10.3 切割理由（Claude）
- **P1 與 P2 分開**：P1 只改資料與掉落，能先驗證存檔、稽核與背包；P2 才碰魔法公式與平衡。兩者各自都可試玩。
- **P4、P5 可以插隊**：兩者不依賴物品。若物品線卡在平衡，可先做它們保持進度。
- **P7 地圖改版放在主城與採集之前、但不提早**：它本身不增加玩法，越晚做越能一次把圓點的種類（戰鬥、採集、主城）定清楚。
- **P10 學院排在主城骨架之後**：升年級改變 `circleTier` 的取得方式，影響範圍大，等主城框架穩定再動。
- **每個專案結束時跑 `tier-curve` 模擬**，守住「所有加成合計不超過下一階中位數」。
