# GM 工具 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在遊戲裡用快捷鍵叫出的浮動 GM 視窗：改自己的元素／素材／關鍵道具、解鎖地圖、看完整配方表、重設其他玩家的密碼；本機與正式上線都要用 GM 名單內帳號的密碼驗證。

**Architecture:** 伺服器：migration 0006（`players.gm_used`、`gm_tokens`、`gm_actions`）、`Store` 新方法、`/api/gm/*`（未設定 `GM_USERNAMES` 時一律 404，在 session 驗證之前判斷）、GM token（30 分鐘、只存雜湊）、改存檔沿用 `serverAction` 並把錨點重設成新存檔。用戶端：`ApiClient` 的 GM 方法、`SyncController.action` 新增兩種 GM 動作、`GmWindow`（浮動、可拖曳、四個分頁）。

**Tech Stack:** TypeScript、Hono（Cloudflare Worker）、D1／SQLite（`node:sqlite` 測試）、React 19、Vitest。

**Spec:** `docs/superpowers/specs/2026-10-23-gm-tool-design.md`（執行者必須兩份都讀；本計畫沒寫到的行為以規格為準）

## Global Constraints

- Branch：從 `feat/core-rework` 開 `feat/gm-tool`；不 push、不合併、不部署。
- 帳本：`docs/superpowers/sdd/2026-10-23-gm-tool/progress.md`（controller 維護）。
- 每個任務完成前 `npm test` 與 `npm run build` 都要通過；採 TDD。
- migration `0006_gm.sql` **不能重置存檔**；SQL 照規格第 6 節原樣。
- `GM_USERNAMES` 未設定或為空 → 所有 `/api/gm/*` 回 404，**在 session 驗證之前**判斷。
- 常數：`GM_TOKEN_TTL_MS = 30 * 60_000`、`GM_ITEM_MAX = 999_999`、`TEMP_PASSWORD_LEN = 12`、快捷鍵 Ctrl＋Shift＋`（`KeyboardEvent.code === 'Backquote'`）、備用入口網址參數 `?gm`、GM token 標頭 `X-GM-Token`。
- GM token 過期／無效：回 **403** `{ error: 'gm_expired' }`（**不能**回 401，避免觸發一般 session 的清除流程）。
- 明文密碼永遠不離開瀏覽器；`gm_actions.detail` 絕不含密碼或雜湊。
- 改存檔只作用在 GM 自己；重設密碼不能對自己、不能對 GM 名單內帳號（403 `not_allowed`）。
- `excludedFromRecords(player) = player.suspicious || player.gmUsed`：發現紀錄改用它。
- 遊戲畫面上不能出現任何 GM 按鈕或入口。
- 介面文字繁體中文；窄 selector；`localStorage` 讀寫 try/catch。
- 改動 `worker/app.ts` 時：`tests/sim` 各路線 0 次被拒、worker 對抗測試全部通過。
- Commit：Conventional Commits（英文），結尾加所用 agent 的 `Co-Authored-By`。

## Review Focus

1. **一般玩家（非 GM）用正確的帳密打 `/api/gm/login`**：403、和錯誤密碼同樣的錯誤碼，不透露是不是 GM。測試在 Task 2。
2. **GM token 過期後打 GM 端點**：403 `gm_expired`，一般 session 仍然有效（`GET /api/save` 照常 200）。測試在 Task 2 與 Task 5。
3. **GM 改存檔後的下一次一般上傳**：不被稽核拒絕，即使改了 `key:` 道具或大量元素。測試在 Task 3。
4. **GM 改存檔時用戶端還有沒同步的進度**：套用後那些掉落還在（GM 變更套在稽核過的用戶端狀態上）。測試在 Task 3。
5. **重設密碼後**：舊密碼 403、臨時密碼可登入、目標原本的 session 全部 401、目標的登入失敗計數被清掉。測試在 Task 4。

  - `ActionResult` 多一種 `{ kind: 'gm' }`（加在 `src/game/api.ts` 的 `ActionResult` union；`messages.ts` 的 `synthMessage` 對它回 `'已套用'`）。

  - 版本衝突 → 409，不寫入、不標記 `gmUsed`。
  - 三種地圖動作各自生效。
  - 沒有 GM token → 403 `gm_expired`。
